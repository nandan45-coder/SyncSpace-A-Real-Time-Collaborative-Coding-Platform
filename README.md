# SyncSpace

**SyncSpace** is a real-time collaborative workspace designed to bring teams together in a single platform for communication, development, document collaboration, file sharing, whiteboarding, meetings, and other collaborative activities.

## Project Overview

SyncSpace aims to provide a unified environment where team members can collaborate efficiently without switching between multiple tools.

The project includes features such as:

* Real-time team collaboration
* Collaborative code editor
* Team chat
* Document collaboration
* File sharing
* Interactive whiteboard
* Online meetings and screen sharing
* Workspace and room management
* User authentication and profiles
* Session recording and replay
* Responsive modern user interface

## Technology Stack

The project is built using technologies including:

**Frontend**

* React
* Vite
* Tailwind CSS
* Zustand
* Socket.IO Client
* Monaco Editor

**Backend**

* Node.js
* Express.js
* MongoDB
* Socket.IO

**Collaboration**

* Yjs
* WebSockets
* WebRTC
